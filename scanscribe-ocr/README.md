# ScanScribe OCR

ScanScribe is a browser-first OCR website for converting scanned documents into editable text.

## What it does

- Upload scanned images or PDF files
- Preview document pages before extraction
- Run OCR in the browser with Tesseract.js
- Copy extracted text or download it as a `.txt` file

## Local setup

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.
