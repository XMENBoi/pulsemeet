ScanScribe Privacy

ScanScribe is designed to process OCR requests in the browser. Uploaded files are not intentionally stored on the server by this demo application.

Document handling

  • Uploaded images and PDFs stay in browser memory while previews and OCR are running.
  • The app serves static files and does not include a document upload API.
  • Third-party OCR assets are loaded from CDNs at runtime, so those requests may be visible to your browser or hosting provider.

Operational data

  • Your hosting stack may still collect standard request metadata even though OCR is designed to run client-side.
  • If you add analytics, storage, or server-side OCR later, update this policy so it matches the real system.
