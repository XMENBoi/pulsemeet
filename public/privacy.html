PulseMeet Privacy Policy

This project uses peer-to-peer WebRTC for live calls, plus a server for signaling, queueing, and moderation workflows.

Data handled by the app

  • Socket connection metadata and IP address can be visible to the server infrastructure.
  • Interest tags and text chat messages pass through the app server for matchmaking and delivery.
  • User reports can be stored in the reports log with room and participant identifiers.

Media handling

  • Camera and microphone access are granted by the browser on the user’s device.
  • WebRTC media is intended to flow directly between peers, but relay TURN servers may carry traffic when needed.
  • If you launch publicly, publish a full retention and moderation policy that matches your actual infrastructure.
